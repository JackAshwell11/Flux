# Flux

Flux is a Rust-based machine learning and reinforcement learning library.

It provides tools for building and training neural networks, working with tensors, and experimenting with reinforcement learning algorithms.

The project is intended as a lightweight, from-scratch implementation of core ML components, with optional GPU compute support.

---

## Features

- Tensor library
- Automatic differentiation
- Neural network modules
- Optimizers
- Reinforcement learning algorithms
- GPU compute experiments (planned)

---

## Tech Stack

- Rust
- (Planned) wgpu for GPU compute
- Optional GUI/visualisation tools

Early development.
